# FinoraOS roadmap

## V1 — Buildathon foundation

- Monorepo, deterministic synthetic dataset, Postgres/Redis compose, reconciliation/evaluation, controlled AI gateway and exception workflow.
- Finance workspace: overview, chat, records, reconciliation and exceptions.
- Evidence-grounded settlement Q&A, baseline tax-line data and cash forecast endpoint.

## V1.x

- Complete gateway adapters for Gemini and OpenAI-compatible providers; real Ollama structured-output evaluation.
- Reconciliation-run trigger/rerun UI, thread persistence and server streaming.
- Better tax matching and a visual forecast.

## Later

- Departments, budget import and spend-vs-budget intelligence.
- Razorpay sandbox, banking/ERP connectors, document ingestion, richer tax workflows, approval policies, notifications, deeper forecasts and autonomous closure under policy.
